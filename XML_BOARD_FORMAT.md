# MiroSQL XML lesson files

Use **XML** in the top toolbar to download a reusable board. Use **Открыть XML** to import it. Import replaces the current shared board, pages and demo database; everyone connected to the same room receives the changes. Export a backup first.

The XML format is intended to be authored manually or generated by AI. It contains the project title, the active page, pages and their positions, card content, strokes, database schemas and rows, assignment evaluations and attempts, SQL results, and builder blocks.

## AI-ready example

```xml
<?xml version="1.0" encoding="UTF-8"?>
<mirosql-board version="1" title="Урок: SQL WHERE" active-page="page_1">
  <database>
    <table name="students">
      <columns>
        <column name="id" type="INT" pk="true" not-null="true" unique="true"/>
        <column name="name" type="STRING"/>
        <column name="gpa" type="FLOAT"/>
      </columns>
      <rows>
        <row>
          <cell name="id" type="number">1</cell>
          <cell name="name" type="string">Анна</cell>
          <cell name="gpa" type="number">3.9</cell>
        </row>
      </rows>
    </table>
  </database>
  <pages>
    <page id="page_1" title="WHERE" type="canvas" scale="1" pan-x="70" pan-y="80">
      <items>
        <item id="lesson_note" type="sticky" x="50" y="50" width="300" height="220">
          <theme>yellow</theme>
          <content>Выберите студентов с GPA больше 3.5.</content>
        </item>
        <item id="task_1" type="assignment" x="400" y="50" width="640" height="540">
          <title>WHERE: задание</title>
          <prompt>Покажите имена студентов с GPA выше 3.5</prompt>
          <expected-query>SELECT name FROM students WHERE gpa > 3.5;</expected-query>
          <query>SELECT </query>
          <attempts/>
          <comments/>
        </item>
        <item id="builder_1" type="sql_builder" x="50" y="340" width="520" height="380">
          <slots><slot>SELECT</slot><slot>name</slot><slot>FROM</slot><slot>students</slot></slots>
          <custom-blocks/>
        </item>
        <item id="quiz_1" type="quiz" x="680" y="640" width="380" height="330">
          <question>Что делает WHERE?</question>
          <explanation>WHERE фильтрует строки.</explanation>
          <correct-index>1</correct-index>
          <options><option>Сортирует</option><option>Фильтрует</option><option>Группирует</option></options>
        </item>
      </items>
      <strokes/>
    </page>
  </pages>
</mirosql-board>
```

## Prompt for an AI assistant

"Generate a complete MiroSQL Board XML v1 lesson about SQL JOIN. Follow the attached example, use unique IDs matching letters/numbers/underscores/dashes, include a realistic database with typed cells, create three pages, at least two assignments, a quiz, a SQL scratchpad and a SQL builder. Use valid XML, escape & as &amp;, and provide only XML."

The board accepts item types: `sticky`, `sql`, `assignment`, `quiz`, `sql_builder`, `checklist`, `erd_table`, `image`. Supported fields are shown in the exported XML from a prepared board. Import limits file size to 6 MB and validates IDs, tables, pages, widgets, and disabled XML entities. Quiz attempts remain per participant, not part of shared XML.
