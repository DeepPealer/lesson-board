# Miro SQL Builder Skill

## Overview
This skill provides best practices and components for interactive visual whiteboard environments equipped with data analytics and SQL query execution widgets.

## Key Capabilities
1. **Infinite Visual Canvas**: Pan, zoom, coordinate transformation between screen space and world space.
2. **Interactive Drawing & Annotation**: High-performance canvas drawing paths with brush styles, colors, line widths, and eraser modes.
3. **Miro-Style Sticky Notes**: Colorful, draggable, resizable text stickies with rich formatting and color swatches.
4. **Media & Image Cards**: Canvas-based image upload and visual embeds.
5. **SQL Scratchpad Widgets**:
   - Monospaced code editor with SQL syntax highlighting, auto-format, and sample query quick-insert.
   - In-memory mock relational database (e.g., student grading, lessons, course analytics).
   - Execution engine that supports SELECT, WHERE, JOIN, GROUP BY, ORDER BY, LIMIT, and custom projections.
   - Interactive data results table with column headers, sorting, row metrics, query timing, and export.
6. **Modern Aesthetics**: Sleek floating pill toolbars, radial/action menus, minimap/zoom controls, subtle dot grid, dark/light theme accents.
