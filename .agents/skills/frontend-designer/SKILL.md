# Frontend Designer Skill

## Overview
This skill guides the design and implementation of visually stunning, highly interactive web applications with modern typography, glassmorphism, responsive navigation, and intuitive tactile micro-interactions.

## Design Tenets
1. **Curated Color Palettes**: Harmonious HSL/slate neutral backdrops paired with vibrant accents (indigo, emerald, amber, rose).
2. **Tactile Micro-interactions**: Smooth hover effects, subtle active press states, crisp shadows, and glassmorphic translucent panels.
3. **Typography**: Pairing modern clean sans-serif UI typography (Inter) with specialized typefaces (JetBrains Mono for code, handwritten styles for whiteboard stickies).
4. **Infinite Canvas UX**: Intuitive panning, smooth cursor-centric zoom, and non-blocking tool switching.
