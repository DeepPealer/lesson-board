# План реализации MiroSQL Studio: Учитель / Ученик & Интерактивная платформа

## 1. Многостраничность (Вкладки страниц доски)
- [ ] Панель вкладок страниц в верхней части доски (+ Добавить страницу, Переименовать, Удалить, Дублировать).
- [ ] Изолированное хранение стейта каждой страницы: масштаб, смещение (pan), штрихи кисти, список виджетов.
- [ ] Сохранение всех страниц в `localStorage` с автоматическим восстановлением при перезагрузке.

## 2. Интерактивная визуальная схема БД (ERD Canvas / Вкладка)
- [ ] Вкладка/вид "Схема БД (ERD)" со всеми таблицами в виде визуальных узлов реляционной схемы.
- [ ] Отображение колонок, типов данных, Primary Key (PK) и связей / Foreign Key (FK).
- [ ] Интерактивное перемещение таблиц на схеме, выделение связей при наведении.

## 3. Расширенное управление базой данных (DDL + DML)
- [ ] Инлайн-редактирование ячеек таблицы: двойной клик или клик по ячейке для изменения значения.
- [ ] Добавление новых строк через модальное окно / форму.
- [ ] Добавление новых колонок в таблицу (имя + тип: INT, STRING, FLOAT, BOOLEAN, DATE).
- [ ] Удаление колонок и переименование.

## 4. Ресайз окон во все 8 сторон (8-Direction Resizing)
- [ ] Добавление ручек ресайза: `n`, `s`, `e`, `w`, `ne`, `nw`, `se`, `sw` для всех карточек и окон.
- [ ] Корректный пересчет координат и размеров с учетом масштаба холста (`scale`) и направления растягивания.

## 5. Полноценный Undo / Redo (Ctrl+Z, Ctrl+Y / Ctrl+Shift+Z)
- [ ] Стек истории для холста (добавление, перемещение, удаление элементов, штрихи).
- [ ] Кнопки Отменить / Повторить в интерфейсе + горячие клавиши.
- [ ] Изолированная история для холста и SQL редакторов.

## 6. Мультиплеер и режим Учитель / Ученик (Multiplayer & BroadcastChannel)
- [ ] Переключатель роли: «Преподаватель» 👨‍🏫 / «Студент» 👩‍🎓 с индивидуальным цветом, именем и курсором.
- [ ] Локальная синхронизация между открытыми вкладками браузера через `BroadcastChannel('mirosql_collab')`:
  - Живое отображение курсора другого пользователя с именем и бейджем.
  - Подсветка выделенных элементов.
  - Follow Mode («Следовать за преподавателем») — авто-перемещение холста ученика за учителем.
  - Spotlight / Лазерная указка — временная подсветка элементов или области доски.
- [ ] Блокировка (Lock) элементов — учитель может заблокировать виджет от перемещения/удаления учеником.

## 7. Образовательные SQL-фичи (Teaching Suite)
- [ ] **Режим задания (Assignment Card):**
  - Условие задачи, описание, ожидаемый результат (целевой SQL / датасет).
  - Чистый SQL-редактор для ученика.
- [ ] **Кнопка «Показать решение»:** скрыто по умолчанию (blur/аккордеон), открывается учителем или по кнопке.
- [ ] **Умная автопроверка запроса (Semantic Query Evaluator):**
  - Сравнение результатов выполнения (колонки, строки, значения), а не просто текста SQL.
  - Эквивалентные запросы с разным форматированием или алиасами считаются верными.
- [ ] **Подсветка ошибок человеческим языком:**
  - Педагогический парсер типичных ошибок новичков (FROM после WHERE, пропущенные запятые, порядок GROUP BY и WHERE).
- [ ] **История попыток:** список предыдущих попыток в карточке задания со статусом, временем и кодом.
- [ ] **Комментарии прямо к коду:** учитель может выделить фрагмент SQL и оставить текстовый фидбек.
- [ ] **Мини-квиз (Quiz Widget):** карточка вопроса с 3–4 вариантами ответа, мгновенной проверкой и объяснением.
- [ ] **Drag & Drop конструктор SQL:** визуальные блоки `SELECT`, `FROM`, `WHERE`, колонки и условия для сборки запроса мышкой.
- [ ] **Трекер прогресса урока (Lesson Checklist):** виджет со статусами тем (`SELECT` ✅, `FROM` ✅, `WHERE` ✅, `AND/OR` 🟡, `ORDER BY` ⬜).
